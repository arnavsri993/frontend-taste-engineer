# Frontend change contract

## Scope

Name the exact route, component, selector, or runtime state; the user-visible outcome; evidence the target exists; and explicit non-goals.

## Preserve

Record product behavior, data, URLs/history, semantics, keyboard/focus, errors/status, responsive order, platform constraints, motion interruption, and reduced-motion outcomes that must remain true.

## Boundary and proof

Name the existing primitive to extend, any external candidate and its license/dependency/a11y/performance review, a safer alternative, rollback boundary, required state fixtures, runtime or screenshot proof, and focused regression checks. Keep request-local content out of this durable template.
